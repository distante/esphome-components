# ESPHome Components — Development Guidelines

All coding standards live in the `coding-standards` skill (`.claude/skills/coding-standards/SKILL.md`). Load it before planning, changing, reviewing or committing anything here, however small. Start every subagent and reviewer prompt with: `Read .claude/skills/coding-standards/SKILL.md first; it is, or links to, every standard of this repo.`

When the user or a later review finds an issue that earlier review rounds missed, ask the user with AskUserQuestion whether to add a check for it to the review skill (`.claude/skills/review/SKILL.md`).
